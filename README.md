# Apex Motors — Homework #26

Сайт автосалона по макету: три вкладки (Mercedes, BMW, Porsche), карточки автомобилей из `data/data.json` и окно с деталями.

## Запуск

Открывайте `index.html` через **Live Server** (VS Code → правый клик → «Open with Live Server»).
Через двойной клик (`file://`) запрос к `data.json` не сработает.

## Структура

```
index.html
css/style.css
js/script.js
data/data.json
images/            ← фото автомобилей (сейчас — заглушки)
```

## Фотографии

В `images/` лежат заглушки с подписью «Фото: …». Чтобы поставить настоящие фото, сохраните их
под теми же именами (`mercedes-s500.jpg`, `bmw-x5.jpg`, …). Код менять не нужно:
пути берутся из поля `image` в `data.json`.

## Что сделано

- Данные загружаются один раз через `axios.get('data/data.json')`
- Карточки и кружки цветов строятся циклом `for` с накоплением строки и одной вставкой в `innerHTML`
- Цена в формате `$185,000` (`toLocaleString('en-US')`)
- Бейдж «Осталась 1» у машин с `count === 1`
- Окно деталей: фото, описание, цена, «В наличии: X шт.», выбор цвета, «Заказать» → `alert`
- Закрытие окна: крестик, клик по фону, `Esc`
- Стекло (`backdrop-filter: blur`), свечения, hover карточек, размытый фон за окном, адаптив под телефон
