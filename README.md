# Apex Motors — Homework #26

Сайт автосалона по макету: три вкладки (Mercedes, BMW, Porsche), карточки автомобилей из `data/data.json` и окно с деталями.

## Запуск

Открывайте `index.html` через **Live Server** (VS Code → правый клик → «Open with Live Server»).
Через двойной клик (`file://`) запрос к `data.json` не сработает.

## Структура

```
index.html
css/style.css
js/script.js
data/data.json
images/            ← фото автомобилей (PNG без фона)
```

## Фотографии

**Mercedes и BMW** — фото без фона, у каждого цвета своё фото. Исходные снимки вырезаны из фона,
остальные цвета получены цифровой перекраской кузова этих же снимков (это не отдельные фотографии).
Какое фото показать для цвета, задаёт поле `colorImages` в `data.json`:

```json
"availableColors": ["#F4F5F6", "#7A2E2E", "#0B0B0D"],
"colorImages": {
  "#F4F5F6": "images/mercedes-c63s-white.png",
  "#7A2E2E": "images/mercedes-c63s-red.png",
  "#0B0B0D": "images/mercedes-c63s-black.png"
}
```

Клик по кружку цвета в окне деталей меняет фото. У машин без `colorImages` фото не меняется.

**Porsche** — пока заглушки «Фото: …». Сохраните настоящие фото (лучше PNG без фона)
под теми же именами (`porsche-911.png`, `porsche-cayenne.png`, …) — пути берутся из поля `image` в `data.json`.

## Что сделано

- Данные загружаются один раз через `axios.get('data/data.json')`
- Карточки и кружки цветов строятся циклом `for` с накоплением строки и одной вставкой в `innerHTML`
- Цена в формате `$185,000` (`toLocaleString('en-US')`)
- Бейдж «Осталась 1» у машин с `count === 1`
- Окно деталей: фото, описание, цена, «В наличии: X шт.», выбор цвета с заменой фото, «Заказать» → `alert`
- Закрытие окна: крестик, клик по фону, `Esc`
- Стекло (`backdrop-filter: blur`), свечения, hover карточек, размытый фон за окном, адаптив под телефон
